A true story from 22 November 2026, when a Cloudflare Turnstile check on Medium kept verifying-then-resetting for the agent, five attempts in a row.

## Run it

```sh
node main.ts
```

This writes the entry line to `/output/entry.txt` — exactly one line, 104 characters, no trailing newline, deterministic.
